# Product-Recommendation-System

The objective of this project is to develop a recommendation system that
can identify relevant products based on customer purchasing behavior and
product relationships.

## Recommendation Techniques

- Popularity-Based Recommendation
- Item-Based Collaborative Filtering
- Cosine Similarity
- Apriori Association Rule Mining

## Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis
4. Customer-Product Matrix Creation
5. Popularity-Based Recommendations
6. Item-Based Collaborative Filtering
7. Cosine Similarity
8. Association Rule Mining using Apriori
9. Streamlit Application

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Apriori

## Key Features

- Recommends popular products
- Finds similar products using collaborative filtering
- Identifies product associations using Apriori
- Provides an interactive Streamlit interface
